
  E-commerce Sales Analysis (SQL Project)

Project Overview
This project focuses on analyzing an e-commerce dataset using SQL to extract meaningful business insights. The goal is to understand sales performance, customer behavior, and product trends.

 Objectives
- Analyze overall sales performance
- Identify top-performing products and categories
- Understand customer purchasing patterns
- Evaluate revenue trends over time.

Tools & Technologies
- PostgreSQL
- SQL
- Excel (for basic visualization)

 Dataset Description
The dataset contains information about:
- Orders
- Customers
- Products
- Sales and revenue



 Key SQL Concepts Used
- SELECT, WHERE
- GROUP BY, ORDER BY
- JOIN (INNER JOIN)
- Aggregate Functions (SUM, AVG, COUNT)
- Subqueries

 Analysis & Insights
 1. Top Selling Products
- Identified products generating the highest revenue

 2. Sales by Category
- Compared performance across different product categories

 3. Customer Behavior
- Analyzed repeat customers and purchasing patterns

 4. Monthly Sales Trend
- Observed sales growth and seasonal trends

 Key Insights
- A small number of products contribute to a large portion of revenue
- Certain categories consistently perform better than others
- Sales show trends based on time (monthly/seasonal)
- Customer retention plays a key role in revenue growth
